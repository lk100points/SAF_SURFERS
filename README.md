# SAF SURF

Ночной браузерный endless runner на Three.js. Проект не использует сборщик, npm или серверную часть: все игровые модели, фургоны, пакетики чая, город и персонаж создаются процедурно в `game.js`.

## Файлы

- `index.html` — разметка экранов, importmap для Three.js и подключение проекта.
- `style.css` — мобильная вёрстка, HUD, меню, магазин и игровые оверлеи.
- `game.js` — сцена Three.js, персонажи, окружение, препятствия, управление, бонусы, экономика и сохранение.
- `README.md` — эта инструкция.
- `music.mp3` — загруженный фоновый трек, воспроизводится по кругу.

## Запуск локально

Для проверки можно открыть `index.html` через любой локальный статический сервер. Например, расширение Live Server в VS Code. Некоторые браузеры ограничивают ES-модули при открытии файла напрямую через `file://`, поэтому локальный сервер надёжнее.

## Публикация на GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория все пять файлов: `index.html`, `style.css`, `game.js`, `README.md`, `music.mp3`.
3. Убедись, что `music.mp3` загружен в ту же папку, что и `index.html`.
4. Открой **Settings → Pages**.
5. В блоке **Build and deployment** выбери **Deploy from a branch**.
6. В качестве ветки выбери `main`, папку — `/ (root)`, затем нажми **Save**.
7. Открой ссылку Pages, которую покажет GitHub. Первый запуск требует подключения к CDN Three.js и Google Fonts.

## Управление

- Свайп влево / вправо — сменить полосу.
- Свайп вверх или короткий тап — прыжок.
- Свайп вниз — скольжение.
- На компьютере: стрелки или WASD, пробел — прыжок / дальше в кат-сцене, Esc — пауза.
- В кат-сцене кнопка «Дальше» ускоряет диалог, «Пропустить» начинает забег сразу.

## Игровые системы

- Три полосы, две сплошные линии разметки, ночной город, мокрые визуальные акценты и туман.
- Полицейские фургоны с детализированной передней частью, ветровым стеклом, дворниками, зеркалами, решёткой и светотехникой; низкие барьеры перепрыгиваются, высокие объезжаются.
- Короткая вступительная кат-сцена с диалогом героя и полицейского. За бегущим героем следует полицейский NPC, который постепенно остаётся позади при разгоне.
- При столкновении запускается отдельная анимация задержания: полицейский догоняет героя, появляются наручники и звучит финальная реплика.
- Пакетики чая собираются по одному и добавляют валюту в постоянный баланс.
- В магазине есть шесть цветов кофты и шесть цветов кроссовок. Покупки и выбранные цвета сохраняются.
- Рекорд, чай, открытые цвета, выбранный комплект и факт показа подсказки хранятся в `localStorage` браузера.
- `music.mp3` автоматически зацикливается после нажатия «Играть»; музыка ставится на паузу вместе с игрой и продолжается при возобновлении.

## Технические замечания

- Three.js фиксирован на версии `0.160.0` через jsDelivr importmap.
- Симуляция использует фиксированный шаг `1/60` с ограничением frame delta.
- Угол обзора в забеге начинается с `62°` и плавно расширяется вместе со скоростью.
- Процедурные Canvas-текстуры добавляют зерно мокрому асфальту, фактуру ткани, окрашенную поверхность фургонов и детализированные этикетки пакетиков.
- Геометрия препятствий, чай, частицы и дорожные сегменты заранее создаются и переиспользуются через пулы.
- Тени отключены ради производительности на мобильных устройствах; глубина сцены создаётся туманом, фактурными материалами, мягкими гало фонарей и двумя локальными источниками света.
- Персонаж собран из округлых сочленённых сегментов, с более сбалансированными пропорциями и печатью SAF на спине.
- Для запуска необходим современный браузер с WebGL и доступом к CDN.


### Новая механика ускорения

Белые пакетики SAF BOOST появляются отдельными группами. Подбор добавляет небольшой временный прирост скорости с плавным затуханием. Они не увеличивают валюту чая и не начисляют отдельные очки. Зелёные пакетики по-прежнему дают чай.


### Новая сюжетная сцена и бонусы

При нажатии «Играть» проигрывается короткий диалог. Его можно ускорить кнопкой «Дальше» или пропустить. После старта за героем бежит полицейский; по мере разгона он постепенно исчезает из кадра. При столкновении преследователь возвращается в сцену, подбегает к герою и завершает забег задержанием.

MATCHA TONIC — безалкогольный редкий бонус для высокого прыжка. AIR-JET — редкий вымышленный реактивный модуль, автоматически поднимающий героя в воздух на пять секунд; в это время обычные столкновения отключены, а приземление сглажено. Белые пакетики SAF BOOST дают примерно вдвое более сильный импульс скорости, чем в предыдущей версии.
